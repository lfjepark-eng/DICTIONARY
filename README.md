# 재무기획팀 백과사전 (FP&A Encyclopedia)

재무를 잘 모르는 리더부터 신입사원까지, 중학교 1학년도 이해할 수 있게 풀어 쓴 전사 재무기획팀 용어 사전입니다.

- 용어 카드 144개, 6개 챕터 (팀의 역할 · 계획과 예산 · 손익 분석 · 현금과 자금 · 투자 판단 · 성과관리와 거버넌스)
- 카드마다 쉬운 설명 + "회사 성과와 연결" + 실무 · 공식 · 예시 · 주의점
- 상단 30초 모션그래픽 영상 (음악은 브라우저에서 실시간 합성한 현악 앙상블, 외부 음원 없음)
- 검색, 난이도 필터(입문/기본/심화), 가나다 색인, 리더용 "회의에서 던질 질문 10개"

## 보기

`index.html`을 브라우저로 열면 됩니다. 단일 파일이라 별도 설치가 필요 없습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 최종 결과물 (빌드 산출물) |
| `shell.html` | 레이아웃 · 디자인 · 검색/필터/색인 스크립트 |
| `parts/ch1~6.html` | 챕터별 용어 카드 |
| `parts/video.html` | 30초 모션그래픽 + 음악 |
| `build.ps1` | `shell.html`에 `parts/`를 끼워 `index.html` 생성 |

수정 후 다시 만들기:

```powershell
.\build.ps1
```

## 주의

예시 숫자와 회사('가상푸드')는 모두 학습용 가상 사례입니다. EBITDA 정의, 투자 승인 기준, 예산 일정 등 회사마다 다른 항목은 사내 기준을 확인한 뒤 적용하세요.
